Diagnosis

What this notice means

A recommended file is missing.

Operational effect

Why it matters

The core schedule can still work, but consumers may miss recommended metadata or service detail.

Scope

Affected files and report fields

The affected file is determined at validation time. Use the filename or related context field in your report to locate it.

Report fieldTypeMeaning
filenamestringThe name of the faulty file.

Repair

How to fix it

Use the filename value in the notice to add the recommended file. If the feature truly does not apply, document that decision.

  1. 1
    Locate the record

    Open the file named in the notice and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Use the filename value in the notice to add the recommended file. If the feature truly does not apply, document that decision.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that missing_recommended_file no longer appears for the record.
