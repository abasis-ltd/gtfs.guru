Diagnosis

What this notice means

Some CSV parsers, such as Univocity, may misinterpret it as a non-empty row that has a single column which is empty, hence we show a warning.

Operational effect

Why it matters

Whitespace-only records are interpreted differently by CSV readers and can become malformed phantom rows.

Scope

Affected files and report fields

The affected file is determined at validation time. Use the filename or related context field in your report to locate it.

Report fieldTypeMeaning
csvRowNumberintegerThe row number of the faulty record.
filenamestringThe name of the faulty file.

Repair

How to fix it

Remove the blank or whitespace-only physical line from the source file before creating the GTFS archive.

  1. 1
    Locate the record

    Open stops.txt and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Remove the blank or whitespace-only physical line from the source file before creating the GTFS archive.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that empty_row no longer appears for the record.

Bad row and correction
