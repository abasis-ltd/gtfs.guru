Diagnosis

What this notice means

The CSV reader could not parse the reported file. The message and position identify where reading failed.

Operational effect

Why it matters

Some or all of the file may be unavailable to later checks, so the report may be incomplete.

Scope

Files to check and report fields

Use the file or input resource identified in the report. Check the message and available context fields; runtime failures may not identify a GTFS row.

Report fieldTypeMeaning
charIndexintegerThe location of the last character read from before the error occurred.
columnIndexintegerThe column index where the exception occurred.

lineIndexintegerThe line number where the exception occurred.
messageobjectThe detailed message describing the error, and the internal state of the parser/writer.
parsedContentobjectThe record number when the exception occurred.

Repair

How to fix it

  1. 1

    Open filename and inspect the parser's message, lineIndex, and nearby text. Check delimiters and balanced quotes.

  2. 2

    Export comma-separated UTF-8 CSV. Quote values containing commas and double any literal quote inside a quoted value; remove unintended line breaks from GTFS field values.

  3. 3
    Check the result

    After a repair, rebuild the archive and validate it again. Confirm that the affected records are correct and that no new related notices appeared. A reviewed warning or informational notice may remain when it describes intentional, supported data.
