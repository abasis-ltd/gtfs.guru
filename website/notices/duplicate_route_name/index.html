Diagnosis

What this notice means

All routes of the same route_type with the same agency_id should have unique combinations of route_short_name and route_long_name.

Note that there may be valid cases where routes have the same short and long name, e.g., if they serve different areas. However, different directions must be modeled as the same route.

Operational effect

Why it matters

Riders can see indistinguishable routes, and consumers may merge or label distinct services ambiguously.

Repair

How to fix it

Give routes in the same agency and mode a unique short/long-name combination. Model opposite directions as trips of one route, not as duplicate routes.

  1. 1
    Locate the record

    Open routes.txt and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Give routes in the same agency and mode a unique short/long-name combination. Model opposite directions as trips of one route, not as duplicate routes.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that duplicate_route_name no longer appears for the record.
