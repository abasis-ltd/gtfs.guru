Diagnosis

What this notice means

The archive contains a filename outside the validator's recognized GTFS files.

Operational effect

Why it matters

The file may be ignored, or its name may hide data that should have been read.

Scope

Files to check and report fields

Use the file or input resource identified in the report. Check the message and available context fields; runtime failures may not identify a GTFS row.

Report fieldTypeMeaning
filenamestringThe name of the unknown file.

Repair

How to fix it

  1. 1

    Check the exact filename, extension, spelling, and purpose.

  2. 2

    Rename a misnamed GTFS file correctly. Remove unrelated export artifacts when unnecessary; retain intentional extensions only with appropriate consumer support.

  3. 3
    Check the result

    After a repair, rebuild the archive and validate it again. Confirm that the affected records are correct and that no new related notices appeared. A reviewed warning or informational notice may remain when it describes intentional, supported data.
