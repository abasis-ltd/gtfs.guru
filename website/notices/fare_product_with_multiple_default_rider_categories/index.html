Diagnosis

What this notice means

The same fare product is linked to multiple categories marked as default.

Operational effect

Why it matters

An app cannot select a single default fare category reliably.

Scope

Files to check and report fields

  • fare_products.txtOpen GTFS specification
  • rider_categories.txtOpen GTFS specification
Report fieldTypeMeaning
csvRowNumber1integerThe CSV row number of the first occurrence of the default rider category
csvRowNumber2integerThe CSV row number of the second occurrence of the default rider category
fareProductIdstringThe ID of the fare product associated with the notice
riderCategoryId1stringThe ID of the first rider category that is marked as default
riderCategoryId2stringThe ID of the second rider category that is marked as default

Repair

How to fix it

  1. 1

    Find the reported product in fare_products.txt and inspect its categories in rider_categories.txt.

  2. 2

    Correct the product links or default flags so that each product has at most one default category. Check other products before changing a shared category.

  3. 3
    Check the result

    After a repair, rebuild the archive and validate it again. Confirm that the affected records are correct and that no new related notices appeared. A reviewed warning or informational notice may remain when it describes intentional, supported data.
