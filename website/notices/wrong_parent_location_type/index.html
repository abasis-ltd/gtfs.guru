Diagnosis

What this notice means

wrong_parent_location_type is an error in a GTFS Schedule validation report: a location points to the wrong kind of parent. Start with stops.txt.

The parent_station ID exists, but the parent's location type is not allowed for the child.

Operational effect

Why it matters

Apps cannot interpret the station hierarchy correctly.

Repair

How to fix it

  1. 1

    Compare the child and parent rows named by the report.

  2. 2

    Use a station (1) as parent for a platform, entrance, or generic node, and a platform (0) as parent for a boarding area. A station must have no parent. Correct the reference or a misclassified type to match the real location.

  3. 3
    Check the result

    After a repair, rebuild the archive and validate it again. Confirm that the affected records are correct and that no new related notices appeared. A reviewed warning or informational notice may remain when it describes intentional, supported data.

Worked example

Example correction

Assume P1 and P2 are platforms of the existing station ST1. P1 must reference that station, not P2.

Before

ST1,1,
P1,0,P2
P2,0,ST1

After

stop_id,location_type,parent_station
ST1,1,
P1,0,ST1
P2,0,ST1
