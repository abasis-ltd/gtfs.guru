Diagnosis

What this notice means

All ferry trips should have a valid value in the bikes_allowed field in trips.txt.

Operational effect

Why it matters

Riders cannot tell whether a bicycle is accepted on ferry journeys.

Scope

Affected files and report fields

  • routes.txtOpen GTFS specification
  • trips.txtOpen GTFS specification

Repair

How to fix it

Set trips.bikes_allowed to 1 or 2 for ferry trips according to the operator policy.

  1. 1
    Locate the record

    Open trips.txt and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Set trips.bikes_allowed to 1 or 2 for ferry trips according to the operator policy.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that missing_bike_allowance no longer appears for the record.
