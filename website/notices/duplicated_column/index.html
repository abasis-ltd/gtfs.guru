Diagnosis

What this notice means

The input file CSV header has the same column name repeated.

Operational effect

Why it matters

This is a GTFS requirement violation. Consumers may reject the affected data or interpret it incorrectly.

Scope

Affected files and report fields

The affected file is determined at validation time. Use the filename or related context field in your report to locate it.

Repair

How to fix it

Use the evidence in the report to identify the failing record, then make the smallest source-data change that satisfies the rule.

  1. 1
    Locate the record

    Open the file named in the validation report and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Apply the requirement described above without changing unrelated rows.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that duplicated_column no longer appears for the record.
