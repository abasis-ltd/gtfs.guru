Diagnosis

What this notice means

The reported file has no column named by fieldName.

Operational effect

Why it matters

The reader cannot obtain required information, even if other columns contain similar data.

Scope

Files to check and report fields

Use the file or input resource identified in the report. Check the message and available context fields; runtime failures may not identify a GTFS row.

Report fieldTypeMeaning
fieldNamestringThe name of the missing column.
filenamestringThe name of the faulty file.

Repair

How to fix it

  1. 1

    Check the first row of filename for a misspelling or an omitted column.

  2. 2

    Add or correctly rename the column and populate required values in its records. Check whether an earlier CSV-format error distorted the header.

  3. 3
    Check the result

    After a repair, rebuild the archive and validate it again. Confirm that the affected records are correct and that no new related notices appeared. A reviewed warning or informational notice may remain when it describes intentional, supported data.
