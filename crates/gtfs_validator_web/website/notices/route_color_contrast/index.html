Diagnosis

What this notice means

A route's color and route_text_color should be contrasting.

Operational effect

Why it matters

Route labels may be unreadable in maps and lists, especially for riders with low vision.

Scope

Affected files and report fields

  • routes.txtOpen GTFS specification
Report fieldTypeMeaning
csvRowNumberintegerThe row number of the faulty record.
routeColorobjectThe faulty record's HTML route color.
routeIdstringThe id of the faulty record.
routeTextColorobjectThe faulty record's HTML route text color.

Repair

How to fix it

Choose route_color and route_text_color with sufficient contrast; test the exact hexadecimal pair used in routes.txt.

  1. 1
    Locate the record

    Open routes.txt and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Choose route_color and route_text_color with sufficient contrast; test the exact hexadecimal pair used in routes.txt.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that route_color_contrast no longer appears for the record.
